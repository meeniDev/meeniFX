# Keyboard shortcuts

Every menu shortcut is also listed inside the application under **Help > Keyboard
Shortcuts**, with search and a warning for conflicting assignments. Shortcuts are ignored
while a text or numeric field has focus.

## Project and files

| Shortcut | Action |
|---|---|
| `Ctrl+N` | New project |
| `Ctrl+O` | Open project |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save as |
| `Ctrl+I` | Import media |
| `Ctrl+R` | Export |
| `Ctrl+Alt+S` | Save the current frame |
| `Alt+F4` | Exit |

## Editing

| Shortcut | Action |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copy / cut / paste (paste also accepts pictures and files) |
| `Ctrl+D` | Duplicate |
| `Ctrl+A` | Select all |
| `Delete` | Delete selection |
| `Shift+Delete` | Ripple delete |
| `C` or `S` | Split at the playhead |
| `Ctrl+L` / `Ctrl+Shift+L` | Link / unlink video and audio |
| `Ctrl+Shift+K` | Toggle linked selection |
| `F2` | Rename the selected marker |
| `Ctrl+T` | Add a text clip |
| `Ctrl+Shift+T` | Key the current text |

## Playback and timeline

| Shortcut | Action |
|---|---|
| `Space` | Play / pause |
| `Home` / `End` | Jump to the start / end |
| `I` / `O` | Set the loop start / end at the playhead |
| `Q` | Toggle loop playback |
| `F8` | Toggle snapping |
| `M` | Add a marker at the playhead |
| `[` / `]` | Previous / next marker |
| `Shift+F` | Add a freeze frame |
| `Ctrl+wheel` | Zoom the timeline |

## Transform and preview

| Shortcut | Action |
|---|---|
| `V` | Selection tool |
| `T` | Transform tool |
| `P` | Puppet Warp |
| `K` | Toggle auto-keyframe |
| `G` | Graph Editor |
| `Shift+G` | Keyframe Editor |
| `Ctrl+Shift+P` | Show motion paths |
| Arrow keys | Nudge by one project pixel (`Shift`: ten) |
| `Shift+F7` / `Shift+F8` / `Shift+F9` | Fit / fill / centre the preview |
| `Shift+F10` | Reset the transform |
| `Esc` | Cancel a drag and drop the overlay selection |

With pins selected in the preview: `Ctrl+C` / `Ctrl+V` copy and paste their keyframes,
`Ctrl+R` resets them, `Ctrl+A` selects all, `L` locks, `Shift+E` disables, `Delete` removes.

## Keyframes and envelopes

| Shortcut | Action |
|---|---|
| `Ctrl+K` | Add a keyframe at the playhead |
| `Ctrl+Shift+C` / `Ctrl+Shift+V` / `Ctrl+Shift+D` | Copy / paste / duplicate selected keys |
| `Delete` | Delete selected keys |
| `Esc` | Cancel a key or envelope drag |

Drag the clip opacity or audio gain envelope to change its value; double-click to key it;
right-click for add/remove key, easing, show/hide and reset.

## Preview cache

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+R` | Render the preview |
| `Ctrl+Shift+E` | Render the selected region |
| `Ctrl+Shift+F` | Performance overlay |

## Fade grips

Drag sideways for length, up/down (or `Alt`+drag) to bend the curve, `Shift` to apply the
fade to the linked clip, right-click for presets, double-click to clear.

## Recording

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+R` | Stop recording (while recording) |
| `Ctrl+Shift+P` | Pause / resume recording (while recording) |
