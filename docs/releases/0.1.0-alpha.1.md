# meeniFX Studios 0.1.0-alpha.1

**Released 8 November 2026 · Alpha**

This is the first public Alpha of meeniFX Studios. It is a real Windows desktop build, but
it is still early software: back up projects you care about and expect rough edges.

## Added

- A multi-track timeline with snapping, markers, fades, linked video and audio, and full
  undo/redo.
- Compositing with blend modes and adjustment layers, plus the Stylize, Warp, Light, Time,
  Glow and keying effects.
- Keyframes on every numeric effect parameter, the Keyframe Editor and the Graph Editor.
- Recording from a webcam, screen, microphone and system audio, including voice-over.
- Auto Captions with a local speech model, a transcript editor and SRT import/export.
- Smart Paste for clipboard pictures, files, direct media links and YouTube videos.
- Export to MP4, AVI, GIF and image sequences, with Save Frame.

## Improved

- Preview playback now keeps the newest rendered frame and uses the cache indicator above
  the ruler, so the picture follows the playhead instead of freezing on one frame.
- Posterize Time has a Frame Rate control in fps instead of a frame count.

## Fixed

- Smart Paste no longer loses a download job while its thread is still running.
- Posterize Time no longer samples backwards when its rate is keyframed.

## Known issues

- Windows only. The editor is not supported on Linux yet.
- Screen recording and some hardware codecs depend on the machine's drivers.
- Auto Captions needs a model download before the first transcription.
- Updates install over the current version; there is no rollback.
