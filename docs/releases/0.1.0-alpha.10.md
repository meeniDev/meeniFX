# meeniFX Studios 0.1.0-alpha.10

Development build. A public installer has not been published for this version.

## Added

- Separate eight-way entry and exit direction controls for Slide In and Slide Out,
  including all four diagonal corners. Keys remain editable in the timeline.
- Windows font discovery includes registered files outside the standard folders.
- A time-bounded, per-module test runner with durable reports for local and release CI.

## Fixed

- The font picker is populated on first opening; Favorites now toggle correctly.
- Decorative font names stay readable, with font-face samples alongside them.
- Fonts without a loadable preview/export face are not offered as working choices.
- In and Out animations share the correct resting position without drifting on edits.
- Skeleton rendering respects the separate Points visibility switch.
- Soft Bloom and Light Wrap control/reset defaults match their rendering defaults.
- Shape value edits keep their inspector controls and scroll position.
- YouTube local-file fallback uses the editor's themed file picker.
- Text-only projects no longer show a misleading "Your project is empty" message.

## Known issues

- Full interactive GUI and installer verification remain release-readiness work.
- The planned Feedback Center is not included in this source update.
- The published Alpha 9 installer does not include these development changes.
