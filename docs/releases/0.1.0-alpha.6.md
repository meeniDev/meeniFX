# meeniFX Studios 0.1.0-alpha.6

**Released 9 November 2026 · Alpha**

This release makes updates finish inside the application. Installed builds now download a
new version in the background as soon as it is found, verify it, and offer one button to
restart and install it. You no longer have to visit the Updates page, download the
installer yourself, or open GitHub.

Windows only for now; back up projects you care about and expect rough edges.

## Added

- **Automatic background downloads.** When an installed Alpha or Stable build finds a
  newer release, it downloads the matching Windows installer immediately while the
  timeline keeps playing. A progress line in the update notice and the Updates page shows
  the transfer.
- **Restart and Install.** Once the SHA-256 checksum matches, the notice changes to
  **Restart and Install**. One click saves your work, closes meeniFX, runs the verified
  installer silently, and reopens the new version.
- **Background downloads survive the Updates page.** Closing the page no longer cancels a
  download; use the explicit **Cancel Download** button or quit the application to stop it.
- **Download updates automatically** in Preferences > Updates. It is on by default and can
  be switched off while automatic checks stay enabled.
- A completed download is reused on the next launch instead of downloading the same
  installer again.

## Fixed

- **Updates now install instead of only being detected.** The previous flow required the
  user to open the Updates page and press Download and Install. The detected update now
  downloads by itself and waits in a clear ready-to-install state.
- **The downloaded installer is never run just because a transfer finished.** The install
  starts only from Restart and Install, after the checksum has been verified, so an
  automatic download can never close the editor on its own.
- **A skipped or postponed release is not downloaded in the background.** Manual checks
  still show and download that release when you ask for it.
- **Portable builds are left alone.** Automatic installation remains limited to the
  installed build; portable users still receive the ZIP from the release page.

## Included from Alpha 5

- Text and shape transform handles no longer crash the preview.
- The transform box follows the visible words or geometry instead of the whole frame.
- Project titles survive opening and saving.
- The Updates page explains an Alpha build on the Stable channel.
- Cursor-anchored zoom, the redesigned Preferences window, bundled presets and looks, and
  the **Getting Started** sample project.

## Known issues

- Windows only. Linux is planned but not officially supported.
- The Alpha self-updater installs over the current version; there is no rollback.
- Installers are checksum-verified but not publisher-signed, so Windows SmartScreen may
  warn about a new download.
- Screen recording and some hardware codecs depend on the machine's drivers.
- Auto Captions needs a model download before the first transcription.

## Updating

Alpha 5 installations on the Alpha channel will detect this release, download it in the
background and show **Restart and Install**. If automatic downloads are switched off, open
**Help > Check for Updates** and press **Download and Install**. The Stable channel still
excludes prereleases.
