# meeniFX Studios 0.1.0-alpha.5

**Released 9 November 2026 · Alpha**

Corrective release for `0.1.0-alpha.4`. Selecting or drawing a text or shape layer in
Alpha 4 raised an `AttributeError` while painting its transform box. Alpha 5 includes the
missing transform function and the regression tests that exercise both layer types.

Windows only for now; back up projects you care about and expect rough edges.

## Fixed

- **Text and shape transform boxes no longer crash the preview.** Alpha 4 called a function
  that was missing from the tagged build, so every paint of a generated layer's handles
  failed. The function is now part of the released source.
- **Transform handles follow the visible content.** Text and shapes are rendered on a
  full-frame transparent layer, but their box now follows the actual words or geometry
  rather than the whole project frame. Position, scale, rotation and anchor still behave
  exactly as before.
- **Project titles survive opening and saving.** The composition breadcrumb no longer
  overwrites the project name with the bare application title.
- **The Updates page explains an Alpha build on the Stable channel.** Stable excludes
  prereleases, so an Alpha installation no longer claims it is on the latest build without
  explaining how to switch to Alpha / Preview.
- **Checksum files use LF on Windows.** `SHA256SUMS.txt` can now be verified with standard
  `sha256sum -c` on every platform.

## Included from Alpha 4

- Cursor-anchored Ctrl+wheel zoom in the Timeline, Keyframe Editor and Graph Editor.
- The redesigned, scrollable Preferences window with nine categories.
- Bundled animation presets, looks and `figure_cafe.png` in installed builds.
- The **Getting Started** sample project with text, shapes, keyframes, a transition, an
  effect and multiple tracks.

## Known issues

- Windows only. Linux is planned but not officially supported.
- The Alpha self-updater installs over the current version; there is no rollback.
- Screen recording and some hardware codecs depend on the machine's drivers.
- Auto Captions needs a model download before the first transcription.

## Updating

Alpha 4 installations should update from **Help > Check for Updates**. The update channel
must be **Alpha / Preview**; Stable does not offer prereleases. Portable builds are updated
by replacing the extracted folder; projects and preferences live outside it.
