# meeniFX Studios 0.1.0-alpha.4

**Released 9 November 2026 · Alpha**

Fourth public Alpha. This release fixes the Preferences window, timeline zoom anchoring,
missing Animations and Styles in installed builds, and the missing default preview image.
It also adds a sample project that works without external media.

Windows only for now; back up projects you care about and expect rough edges.

## Fixed

- **Preferences no longer runs off the screen.** The single long page is now a compact
  dialog with a category sidebar and an independently scrollable page for each group. It
  fits a 1366 x 768 display, remembers the last category, and keeps the title simply
  "Preferences".
- **Timeline, Keyframe Editor and Graph Editor zoom at the pointer.** Ctrl+wheel now keeps
  the frame under the cursor in place in all three editors. The Graph Editor's vertical
  zoom moved to Ctrl+Shift+wheel, and Shift+wheel pans.
- **Animations and Styles are present in installed builds.** The shipped `presets` and
  `looks` folders were never added to the PyInstaller data list, so the tabs were empty in
  the installer and portable ZIP even though they worked from source. Both folders now
  ship with the application.
- **The default effect preview is present in installed builds.** `figure_cafe.png` is now
  bundled and resolved through the same resource root as the rest of the application, so
  thumbnails load after a fresh installation. A custom preview image still takes
  precedence and falls back to the bundled image when it cannot be read.
- **Long settings labels and paths no longer run into the edge.** Paths use read-only
  fields with full-path tooltips, technical renderer text is shortened to "Renderer: CPU"
  or "Renderer: GPU", and the full hardware details are available under Details.
- **Empty browser text is specific.** Effects, Animations and Styles now say which list is
  empty instead of the generic "Nothing here yet."

## Added

- **A real sample project.** *Getting Started.mfxpf* contains text and vector shape layers,
  keyframe animation, a crossfade between two shapes, a glow effect and three video tracks.
  It uses no external media, so nothing needs relinking. Open it from the start window or
  **File > Open Sample Project**. The first open copies it to Documents, leaving the
  installed example untouched.

## Improved

- Settings are grouped into General, Appearance, Timeline, Playback, Recording, Import,
  Captions, Cache and Updates. Cache budgets and location are separate from playback
  controls, and recording quality is editable.
- The dialog supports mouse-wheel, touchpad and keyboard navigation, high-DPI rendering,
  and minimum/default sizes that do not exceed the available screen.
- User-facing text was reviewed for unnecessary filler, and em dashes were removed from
  interface strings and documentation.

## Known issues

- Windows only. Linux is planned but not officially supported.
- The Alpha self-updater installs over the current version; there is no rollback.
- The sample project is intentionally short and uses generated layers rather than footage.
- Screen recording and some hardware codecs depend on the machine's drivers.
- Auto Captions needs a model download before the first transcription.

## Updating

Alpha builds can update from **Help > Check for Updates**. Portable builds are updated by
replacing the extracted folder; projects and preferences live outside it.
