# meeniFX Studios 0.1.0-alpha.7

**Released 9 November 2026 · Alpha**

Alpha 6 introduced the integrated updater but could not download the installer. GitHub now
redirects release assets to `release-assets.githubusercontent.com`, and the downloader's
trusted-host check rejected that redirect after the update had already been detected. This
release allows GitHub's current asset host and proves it with a redirect regression test.

Windows only for now; back up projects you care about and expect rough edges.

## Added

- Support for GitHub's current signed release-asset host in the updater's checksum and
  installer downloads, with a redirect-lookalike regression test.

## Fixed

- **Automatic update downloads work again.** Checksum files and installers are fetched from
  GitHub's current `release-assets.githubusercontent.com` host. Downloads are still
  restricted to this repository's release assets and their signed GitHub redirects.
- **Updates no longer stop after detection.** The Alpha 6 notice could find a new version
  and then report a download failure. Alpha 7 downloads the verified installer, changes the
  notice to **Restart and Install**, and finishes the update from inside the app.
- **A redirect lookalike is still rejected.** Only the exact GitHub asset hosts are
  accepted; a host such as `release-assets.githubusercontent.com.evil` cannot pass the
  check.

## Included from Alpha 6

- Automatic background downloads for installed builds, so the timeline keeps playing while
  the installer is fetched.
- **Restart and Install** saves the project, installs the checksum-verified update and
  reopens the new version.
- **Download updates automatically** in Preferences > Updates, on by default.
- Background downloads survive closing the Updates page and completed downloads are reused.
- Skipped or postponed versions are not downloaded automatically.
- Text and shape transform handles no longer crash the preview.
- The redesigned Preferences window, cursor-anchored zoom, bundled presets and looks, and
  the **Getting Started** sample project.

## Known issues

- Windows only. Linux is planned but not officially supported.
- The Alpha self-updater installs over the current version; there is no rollback.
- Installers are checksum-verified but not publisher-signed, so Windows SmartScreen may
  warn about a new download.
- Screen recording and some hardware codecs depend on the machine's drivers.
- Auto Captions needs a model download before the first transcription.

## Updating

Alpha 6 installations cannot download this release automatically because they contain the
redirect bug. Install Alpha 7 manually from this release once. Alpha 7 and later can use
**Help > Check for Updates** and the built-in background downloader.

The Stable channel still excludes prereleases. Portable builds are updated by replacing the
extracted folder with the newer ZIP.
