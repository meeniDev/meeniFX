# meeniFX Studios 0.1.0-alpha.8

**Released 9 November 2026 · Alpha**

Opening meeniFX Studios several times, or letting the installer reopen it after an update,
could leave a row of identical windows on screen. The app had no single-instance guard, so
every process owned its own start window. Alpha 8 allows one running editor per Windows
account; later launches wake that editor and exit.

Windows only for now; back up projects you care about and expect rough edges.

## Added

- A per-user single-instance guard. A second shortcut click, file association or installer
  relaunch focuses the existing window instead of opening another copy.
- Project forwarding: opening a project while meeniFX is already running asks the existing
  window to open it, with the normal save prompt first, so the current timeline is not
  replaced without asking.

## Fixed

- **No more stacks of meeniFX windows.** Ten launches can no longer produce ten copies of
  the start screen. The duplicate process exits immediately after waking the first one.
- **Silent updates reopen one window.** The installer still relaunches the new build after
  an update, but the relaunch can no longer add a second copy beside it.
- **Automatic update downloads still work.** This build includes the Alpha 7 fix for
  GitHub's current release-asset redirect host.

## Known issues

- Windows only. Linux is planned but not officially supported.
- The Alpha self-updater installs over the current version; there is no rollback.
- Installers are checksum-verified but not publisher-signed, so Windows SmartScreen may
  warn about a new download.
- Screen recording and some hardware codecs depend on the machine's drivers.
- Auto Captions needs a model download before the first transcription.

## Updating

Install Alpha 8 once from this release. It can then download and install Alpha 9 and later
from inside the app. Portable builds are updated by replacing the extracted folder with the
newer ZIP; the single-instance guard applies there too.
