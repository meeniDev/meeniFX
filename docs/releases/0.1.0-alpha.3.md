# meeniFX Studios 0.1.0-alpha.3

**Released 9 November 2026 · Alpha**

Third public Alpha, and the corrected replacement for `0.1.0-alpha.2`. The Roto Brush work
is the same; this build exists because Alpha 2's tagged source did not import and its
installer was never built. This release ships the portable ZIP **and** the Windows installer.

Windows only for now; back up projects you care about and expect rough edges.

## Fixed

- The committed Roto Brush mouse-press handler is restored. The Alpha 2 tag put part of it
  in the wrong block, so importing the preview overlay raised `IndentationError` and the
  release workflow stopped before packaging.
- The installer's Windows version resource now uses the numeric version. Inno Setup rejects
  a prerelease string such as `0.1.0-alpha.2`, which is why earlier workflow runs could not
  produce a Setup executable even when the tests passed.

## Added

- A Windows installer is attached to this Alpha for the first time, alongside the portable
  ZIP and SHA256 checksums. No Roto Brush behaviour, project format or settings changed from
  Alpha 2.

## Roto Brush is a real rotoscoping tool

The old Roto Brush clicked and erased; this rebuild turns it into the workflow the tool was
meant to have:

- **A dedicated mode.** Activating Roto Brush hides the transform box, handles and motion
  path, shows a circular brush cursor, and adds an obvious **Done** button (or `Esc`). The
  clip's transform is untouched, and the normal tools return when you leave.
- **Green / red / Refine Edge brushes.** Drag green inside the subject to keep it, hold Alt
  to drag red over what should go, and press `B` for the Refine Edge brush on hair, fur and
  soft boundaries. Strokes are hints for the segmenter, they are never painted into the
  footage and never delete pixels.
- **A segmentation outline.** The purple outline follows the actual matte boundary rather
  than a box around the clip, updates after every stroke, and can be hidden with `O`.
- **A base frame.** The first stroke marks the base frame. Correct later frames with their
  own strokes; each correction belongs to that source frame.
- **Forward, Backward and Analyze All.** Propagation carries the mask with optical flow and
  refines it on each frame, with a progress bar and **Stop**. Frames that were never analysed
  are left alone rather than filled with a stale mask.
- **Matte previews and controls.** Composite, transparent checkerboard, alpha matte and
  foreground on a solid colour; Smooth, Feather, Choke/Expand, Edge Contrast, Edge Colour
  Cleanup, Search Radius, Colour Tolerance and Quality all change the result. A
  half-quality preview now shapes the edge exactly like the export.
- **Freeze.** Freeze keeps the analysed masks on disk so previews stop re-segmenting;
  Unfreeze, Recalculate and Clear Cache manage them. Editing a stroke after freezing warns
  you and invalidates the stale masks. Nothing is written into the source media.
- **Trims, speed, reverse and transforms stay correct.** Strokes and masks are keyed by the
  clip's *source* frame, so trimming, moving or transforming the clip cannot shift them.
- **Persistence that stays small.** `.mfxpf` keeps the base frame, strokes, settings,
  propagation range and cache metadata; the frame-by-frame masks live in a per-clip cache
  folder. Reopening without that cache reports which frames need analysing.

The shipped segmenter is a clearly labelled classical fallback: OpenCV GrabCut seeded by the
strokes, a colour model, a guided-filter edge refinement and Farneback optical flow. It is
not a learned video-segmentation model, so fast motion, occlusion, motion blur and fine hair
still need corrections. SAM 2 / SAM 2.1 and its ONNX exports (Apache-2.0, 110–770 MB
checkpoints, PyTorch / WSL on Windows) are documented as the upgrade path in
`docs/ROTO_BRUSH.md`; none is bundled, and the UI does not pretend otherwise.

## Also in this Alpha

- Pre-compositions with nested audio routing, composition navigation, Render Composition and
  a per-composition cache, all as one undo step where they edit the timeline.
- Smart Key: a border-sampled, soft YCbCr key with spill suppression and matte views.
- Posterize Time's Frame Rate field keeps 23.976 / 29.97 / 59.94 exact.
- Preview caching invalidates parent frames when a nested composition changes; Roto Brush
  matte shaping follows the preview scale; edge colour cleanup removes a bright or green
  fringe; fully transparent and unanalysed Roto frames are left unchanged.

## Known issues

- Windows only. Linux is planned but not officially supported.
- The classical Roto Brush segmenter is weaker than a learned model on hair, fur,
  semi-transparent edges and fast or occluded motion; paint corrections on those frames.
- Screen recording and some hardware codecs depend on the machine's drivers.
- Auto Captions needs a model download before the first transcription.
- Updates install over the current version; there is no rollback.

## Updating

Alpha 1, Alpha 2 and Alpha 3 builds can update from **Help > Check for Updates**. Alpha 2
users should move to Alpha 3: it is the first Alpha with an attached installer and its
tagged source builds cleanly. Portable builds are updated by replacing the extracted
folder; projects and preferences live outside it.
