# meeniFX Studios 0.1.0-alpha.9

**Released 11 November 2026 · Alpha**

Text editing is now a full typography tool: the editor discovers every font installed on the
computer, keeps the preview and export on the same layout, and can split a title into
independent characters, words or lines without moving anything on screen. This build also
includes the Alpha 5 preview fix, so it replaces Alpha 4 installations that reported a
missing `content_corners_rect` transform helper.

Windows only for now; back up projects you care about and expect rough edges.

## Creative Tools Update, Part 3

This build adds a professional effect library alongside the typography work.

- **Five separate Glow effects:** Multi-Glow combines up to six light scales, Neon Glow
  builds a bright filament and wide halo, Soft Bloom rolls off highlights into haze, Light
  Wrap spills an alpha edge into the layer, and Directional Glow stretches light along an
  angle. Threshold, radius, colour, saturation, falloff, blend, quality and mix are
  keyframeable, and transparency is softened instead of painted with a hard fringe.
- **Colour grading:** Curves has a draggable master/RGB graph and monotone cubic output;
  Hue/Saturation, Tint, Tritone, Levels and Color Wheels complete the set. Color Wheels use
  interactive lift, gamma and gain trackballs.
- **Distortion:** Turbulent Displace, animated Lens Distortion and Displacement Map, which
  can read another clip or an image with a chosen channel and axis scales.
- **Generators:** Gradient Ramp, Fractal Noise with scale, complexity, contrast, brightness,
  evolution and seed, plus Checkerboard and Grid with transparent-background modes.
- **Matte Choker** chokes or grows an alpha edge with feather, softness, iterations and hole
  closing. Set Matte was already part of the track-matte workflow.
- **Browser and editor integration:** alphabetical categories, search keywords, Favorites,
  Recently Used, distinct icons and renderer-generated previews. Displacement Map has clip
  and image pickers; curve and wheel editors edit the same keyframeable parameters as the
  numeric fields.

The new effects work in previews and exports with masks, adjustment layers, nested
compositions and `.mfxpf` projects. Measured 1080p averages range from 78 ms (Lens
Distortion) to 413 ms (Multi-Glow) per frame on the test machine; the complete results are
in `artifacts/benchmarks/creative-part3.json`.

## Added

- **Installed-font picker.** A searchable list with each family's own sample, Favorites,
  Recently Used, Refresh Fonts and a missing-font section. Font files are resolved from the
  system and per-user font folders, so preview, timeline thumbnails and export agree.
- **Typography controls** for bold, italic, underline, strikethrough, left/centre/right/
  justify alignment, case conversion, block anchor, letter/word/line spacing, gradient fill,
  outline opacity, shadow distance and angle, and rounded background plates. Advanced
  options are collapsed by default so the inspector stays readable.
- **Text > Split Text** for characters, words and lines, also available from a clip's
  right-click menu. Split pieces keep their on-screen positions, including kerning, spacing,
  alignment and transforms, and each piece can be positioned, scaled, rotated, faded,
  animated and timed independently.
- **Split options:** Replace Original, Keep Original Hidden (on a hidden video track) or
  Duplicate and Split, with optional stagger animation for the new pieces. No animation is
  applied unless a stagger preset is chosen, and the whole split is one undo step.
- **Grapheme-safe splitting:** combining marks, emoji sequences and flags stay whole. For
  scripts that need contextual shaping, character mode explains that words or lines preserve
  the joining, while words/lines keep the shaped layout intact.

## Fixed

- **The Alpha 4 preview crash is gone.** `content_corners_rect` is present in the transform
  module, and a regression test covers the text and shape transform handles that call it.
- **Formatting buttons are recognisable.** Bold, italic, underline, strikethrough and the
  alignment controls use the editor's vector icons with hover, checked and tooltip states
  instead of blank or squeezed labels.
- **A missing font is named, not silently substituted.** The inspector shows the family and a
  Replace action, and updates immediately when the selected font changes.
- **Cleaner Qt test teardown.** Split Text and the panel tests no longer leave top-level
  widgets that made the combined suite exit with status 127.

## Known issues

- Windows only. Linux is planned but not officially supported.
- The Alpha self-updater installs over the current version; there is no rollback.
- Installers are checksum-verified but not publisher-signed, so Windows SmartScreen may
  warn about a new download.
- Background plates are per text block; a character/word split cannot transfer one plate to
  each piece, which the Split Text dialog explains.
- Screen recording and some hardware codecs depend on the machine's drivers.
- Auto Captions needs a model download before the first transcription.

## Updating

Install Alpha 9 over an older Alpha from this release, or replace an extracted portable
folder with the newer ZIP. Alpha 5 and later already contain the transform fix; projects
saved by older builds open without migration.
